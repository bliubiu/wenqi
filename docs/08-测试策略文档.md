## 1. 测试理念

### 1.1 核心原则

1. **TDD 驱动**：核心领域逻辑以测试先行编写，测试即规格。
2. **金字塔结构**：大量单元测试、适量集成测试、少量 E2E 测试。
3. **快速反馈**：单元测试执行时间 < 5 秒，集成测试 < 30 秒，E2E < 3 分钟。
4. **中文友好**：测试用例描述使用中文，与业务语言一致。
5. **独立性**：每个测试用例独立运行，不依赖执行顺序，可并行执行。

### 1.2 TDD 工作流

```
红灯（RED）         绿灯（GREEN）        重构（REFACTOR）
写一个失败的测试  →  写最少代码通过测试  →  优化代码结构
```

- 领域层核心算法（评分、布局、聚类）必须遵循 TDD 流程。
- 应用层用例推荐 TDD，不强制。
- 基础设施层和表现层不强制 TDD，但必须有测试覆盖。

## 2. 测试金字塔

```
        ▲
        │   E2E 测试（Playwright）                         少量
        │  ───────────────────────────────────────
        │   集成测试（Vitest + WASM + fake-indexeddb）      适量
        │  ───────────────────────────────────────────────────
        │   单元测试（Vitest + wasm-bindgen-test）           大量
        │  ───────────────────────────────────────────────────
        ▼
```

### 2.1 各层定位

| 层级 | 数量 | 执行时间 | 对象 | 工具 |
| --- | --- | --- | --- | --- |
| 单元测试 | 大量 | < 5s | 值对象、实体、领域服务、Rust 函数 | Vitest / wasm-bindgen-test |
| 集成测试 | 适量 | < 30s | 用例编排、WASM 桥接、仓储实现、日志、**数据契约接口** | Vitest + fake-indexeddb |
| E2E 测试 | 少量 | < 3min | 完整用户路径（初始化、聚气、搜索） | Playwright |

### 2.2 集成测试覆盖三类接口

首版为纯客户端应用，无后端 HTTP 服务。集成测试层承担以下三类接口的测试职责，等同于传统项目的「API 测试」：

| 接口类型 | 通信双方 | 集成测试重点 | 章节 |
| --- | --- | --- | --- |
| 应用层用例接口 | 表现层 ↔ 应用层 | 用例编排、DTO 转换、异常处理 | 4.3 |
| WASM 计算接口 | 应用层 ↔ Rust WASM | 接口签名、数据格式、错误传递 | 4.4 |
| 数据契约接口 | 基础设施层 ↔ 数据源 | JSON 结构、版本兼容、分片加载 | 4.4 |

export class MockPoetRepository implements PoetRepository {
  private poets: Map<string, PoetAggregate> = new Map();

  setPoets(poets: PoetAggregate[]): void {
    poets.forEach(p => this.poets.set(p.poet.id.value, p));
  }

    return this.poets.get(id.value) ?? null;
  }

  async findByIds(ids: PoetId[]): Promise<PoetAggregate[]> {
    return ids.map(id => this.poets.get(id.value)).filter(Boolean) as PoetAggregate[];
  }

  async findAll(): Promise<PoetAggregate[]> {
    return Array.from(this.poets.values());
  }

  async findByDynasty(dynasty: DynastyCode): Promise<PoetAggregate[]> {
    return Array.from(this.poets.values()).filter(p => p.poet.dynasty === dynasty);
  }
}

export class MockEventBus implements EventBus {
  private handlers: Map<string, Set<(event: DomainEvent) => void>> = new Map();

  publish(event: DomainEvent): void {
    const subs = this.handlers.get(event.eventType);
    if (subs) subs.forEach(handler => handler(event));
  }

  subscribe<T extends DomainEvent>(
    eventType: string,
    handler: (event: T) => void,
  ): () => void {
    if (!this.handlers.has(eventType)) {
      this.handlers.set(eventType, new Set());
    }
    this.handlers.get(eventType)!.add(handler as (event: DomainEvent) => void);
    return () => this.handlers.get(eventType)?.delete(handler as (event: DomainEvent) => void);
  }
}
